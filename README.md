# ◈ BEYOND THE CODE

</div>

I’m **Shreya**, a Computer Science and Business Systems student drawn to the intersection of **data, intelligence and automation**.

What interests me isn't only building something that works.

It is understanding the layer underneath:

> **Why did the model make that decision?**  
> **How did the system find the right context?**  
> **What happens when the knowledge base grows?**  
> **Can an AI agent actually complete the workflow?**  
> **Where does the system break?**

That curiosity has taken me from **Data Analysis → Machine Learning → Generative AI → RAG → AI Agents**.

And I’m still following the questions.
